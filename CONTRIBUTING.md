# Contributing

Corrections and additions are welcome.

## What helps most

- **A broken link, or a wrong claim.** Open an issue with the link or the sentence, and the correct source.
- **A question you were actually asked** in an AI-for-simulation interview. Mention the role type and the year; do not name interviewers or share anything under NDA.
- **A better primary source** for an existing answer (a paper, documentation, a lecture).

## Rules for new content

1. Every factual claim needs a source a reader can open.
2. Prefer primary sources (papers, official docs, lectures) over blog summaries.
3. Code on answer pages must run. State the library versions if they matter.
4. Keep answer pages focused: a short answer first, then the details, then the references.
5. Company facts must carry a date ("as of …").

## Format

Questions follow the same pattern as the rest of the README:

```markdown
- Question text?
  - Answer: [Answer page](answers/page.md) and [Primary source](https://...)
```
